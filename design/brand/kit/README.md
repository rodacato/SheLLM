# SheLLM brand kit

The current identity and marketing materials, packaged together. Start with the
[visual guide](guide/index.html) for logo use, color roles, typography and voice, or preview the
[landing page](marketing/index.html). All product copy is English.

This folder is generated by `npm run brand:pack` in the SheLLM repository. Its source of truth
is `design/brand/` there; nothing here is edited by hand.

Use the logo's existing proportions and leave clear space at least as high as the cursor. Keep
the cyan cursor and the two Ls together. Use the standalone mark for icons, and preserve the
maskable composition's opaque background and safe area. SVG lettering uses outlines and needs
no installed font. The editable [mark](assets/logo/mark.svg), [wordmark](assets/logo/wordmark.svg)
and [social composition](assets/brand/social-source.svg) retain the source geometry.

`social.png` is ready for the repository's **Settings → Social preview → Upload an image**.
The landing already references the same card through its Open Graph and Twitter metadata.

## Preview

Open `guide/index.html` in a browser. For the landing's recorded request demo, serve the folder
over HTTP so the browser can fetch its local JSON:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Open <http://127.0.0.1:8080/guide/> or <http://127.0.0.1:8080/marketing/>. Any static HTTP server
works. Images, styles and demo data are included. Google Fonts, API documentation and repository
links need a connection; local system fonts are the fallback. The demo replays recorded fixtures
and does not call an LLM.

## Voice and licensing

Explain what connects to what: one owner's apps, their own subscriptions, the official CLIs and
the two API formats. Describe observed usage and its limits; an API equivalent is not a charge
or remaining subscription quota. Keep provider-risk qualifications when reusing marketing copy.
Never add endorsements, adoption figures or safety guarantees the product cannot substantiate.
