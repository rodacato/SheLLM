Identidad del proyecto

Una interfaz entre tus apps y los CLI que ya usas.

SheLLM conecta el software de un propietario con sus propias suscripciones mediante los CLI oficiales. La identidad toma su forma de esa actividad: el prompt de terminal >_, líneas directas y un acento cian.

El símbolo

El chevron abre el prompt; la línea cian funciona como cursor y enlaza con las dos letras L del nombre. Mantén la geometría y las proporciones del SVG. El logo está hecho de trazados: funciona sin descargar fuentes.

Deja alrededor del logo al menos el alto de su cursor. Usa el símbolo solo para favicon y acceso instalado. El icono maskable tiene fondo opaco y una composición que cabe en la zona segura circular; conserva ese archivo al exportar para Android.

Tipografía y forma

Space Grotesk da nombre y jerarquía; Inter lleva la explicación; el stack monoespaciado del sistema muestra requests, comandos y datos. Las esquinas rectas y el espacio entre grupos mantienen el carácter de herramienta.

Cómo habla SheLLM

Describe el resultado, el dato y su límite. Usa verbos concretos. El equivalente en API es una estimación, no un cargo; la instalación es un acceso al dashboard, no una promesa de trabajo sin conexión. Evita garantías que el producto no puede demostrar.
