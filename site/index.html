Your LLM subscription — as a REST API for your own apps

A personal project for experimenting on the subscriptions you already pay for, through the official, unmodified CLIs — the lowest-risk way to do it.

What it is

A personal project: experiment with LLMs from your own software on the Claude Code or Codex subscription you already pay for, instead of buying API credit on top. SheLLM runs the official CLI behind one endpoint that answers in both the OpenAI and the Anthropic formats.

You already pay the subscription, so the marginal request costs nothing extra — and for Claude the CLI reports what it would have cost on the API, attributed to the key that made it. That is the figure above.

Every request starts the CLI and pays for it — about 0.9 s of a short call on the server, a cold start that is permanent. Streaming is what makes it usable: claude-sonnet starts writing at 1.7 s of a 5.5 s request (measured).

Inside a request

Four requests, played through SheLLM. Pick one and watch what it becomes on the way to the CLI and back.

Nothing here is typed by hand. The argv, the responses and the log rows come from running each request through the app against CLI output recorded from claude 2.1.273 and codex 0.154.0 — and a test fails the day any of it stops being true.

      import OpenAI from 'openai';

const client = new OpenAI({ baseURL: 'http://127.0.0.1:6100/v1', apiKey: process.env.SHELLM_KEY });

const stream = await client.chat.completions.create({
  model: 'claude-sonnet',
  messages: [{ role: 'user', content: 'Hello' }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? '');
}
      
        
      
      
      
      

      import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic({ baseURL: 'http://127.0.0.1:6100', apiKey: process.env.SHELLM_KEY });

const stream = client.messages.stream({
  model: 'claude-sonnet',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'Hello' }],
});
stream.on('text', (text) => process.stdout.write(text));
await stream.finalMessage();

      When it does not work
      
    
      
      
      A setting you changed did nothing.The config file is read once, when the service starts. Restart it: sudo systemctl restart shellm on a server, shellm restart on your machine.
      
      
      A browser page is blocked by CORS.Calling /v1 from a page is off until SHELLM_CORS_ORIGINS names that exact origin — scheme, host and port, no trailing slash, and no wildcard.
      
      
      curl works and your app gets 403.That key is scoped to browser origins, and yours is not on its list. A request with no Origin is accepted, which is why curl still works.
      
      
      Anything else.shellm doctor checks the install and prints the fix beside whatever failed. shellm doctor --live spends one real request to prove the whole path.
      
    
      
  
      

      


      
  
      
    
      What it is not
      
    
      
      
      Not a way to share a subscription.One owner, their own apps.
      
      
      Not a backend for coding agents.They drive their own CLI already.
      
      
      Not an API-key gateway.LiteLLM does that better — how they differ.
      
      
      Not machine-scale.Quota is measured in human sessions.
      
    
      
  
      

      


      
  
      
    
      How it compares
      
    
      The most-used projects in this space, one per kind. They differ less in features
      than in how they reach the model — and that is what decides who carries the risk.
      
    
      
      
      
        
      LiteLLM
      
        
      API-key gateway
      
        
      
          
      Reaches the model through
      Paid API keys, across many providers.
      
          
      Built for
      Teams: budgets per team, user and key.
      
          
      Pick it when
      You pay per token and want one endpoint over all of it.
      
        
      
      
      
      
      
        
      CLIProxyAPI
      
        
      Subscription proxy
      
        
      
          
      Reaches the model through
      OAuth login to Claude Code and Codex, round-robin across several accounts.
      
          
      Built for
      Pooling subscriptions behind one API.
      
          
      The catch
      The login is used outside the official client — the route Anthropic's terms forbid.
      
        
      
      
      
      
      
        
      new-api
      
        
      Multi-tenant gateway
      
        
      
          
      Reaches the model through
      Upstream API keys, configured as channels.
      
          
      Built for
      Serving other people: quotas, subscriptions and billing per user.
      
          
      Pick it when
      You run a gateway for a team or for customers.
      
        
      
      
      
      
      
        
      SheLLM
      
        
      Subscription wrapper
      
        
      
          
      Reaches the model through
      The official, unmodified CLI, which keeps its own login.
      
          
      Built for
      One owner and their own apps. No sharing, no pooling.
      
          
      The catch
      Slower: every request starts the CLI. Codex still carries classifier risk.
      
        
      
      
      
    
      
  
      

      


      
  
      
    
      Fair use and provider terms
      
    
      
      SheLLM runs the official, unmodified CLI binaries. It never extracts OAuth tokens, never
      calls a provider's API with subscription credentials, and never pretends to be a different
      client. The remaining risk is yours.
    
      
    
      
      
      ProviderStatus
      
      
        
      
          Claude
          Supported. Anthropic forbids intermediating Claude.ai credentials; the official binary keeps its own login.
        
      
        
      
          Codex
          Supported, at your own risk. codex exec is documented for scripts; anti-abuse classifiers are the real exposure, and a suspension takes the whole ChatGPT account.
        
      
        
      
          Gemini
          Not supported. Gemini CLI stopped serving personal plans, and Antigravity's terms forbid it.
