Your LLM subscription — as a REST API for your own apps

API Docs GitHub

What it is

You pay for Claude Code or Codex. Your own apps cannot use that subscription — they need API credit you would buy separately. SheLLM runs the official CLI you already have, behind one HTTP endpoint that answers in both the OpenAI and the Anthropic formats, so an official SDK pointed at it works on the first try.

What it is not

  • Not a way to share a subscription. One owner, their own applications. No multi-tenant mode, no reselling capacity.
  • Not a backend for coding agents. Claude Code, Cline, Aider and friends drive their own CLI; putting SheLLM in between adds latency and breaks their terms.
  • Not an API-key gateway. If you pay per token, LiteLLM and OpenRouter do that better.
  • Not machine-scale. Subscription quota is measured in human sessions, not throughput.

Get started

# Requires Node.js 24 and a logged-in claude (or codex) on the same machine
git clone git@github.com:rodacato/SheLLM.git && cd SheLLM
npm install && npm link
shellm init # config file, token, first API key, checks
shellm start

# Any official SDK, no code change
export OPENAI_BASE_URL=http://127.0.0.1:6100/v1 OPENAI_API_KEY=$SHELLM_KEY
export ANTHROPIC_BASE_URL=http://127.0.0.1:6100 ANTHROPIC_API_KEY=$SHELLM_KEY

Fair use and provider terms

SheLLM runs the official, unmodified CLI binaries and nothing else. It never extracts OAuth tokens, never calls a provider's API with subscription credentials, and never pretends to be a different client. Running your own subscription through your own software still carries risk, and it is yours.

ProviderStatus
Claude Supported. Anthropic's terms forbid intermediating Claude.ai credentials; SheLLM spawns the official binary, which keeps its own login.
Codex Supported, at your own risk. OpenAI documents codex exec for scripts, but anti-abuse classifiers are the real exposure and a suspension takes the whole ChatGPT account.
Gemini Not supported. Gemini CLI stopped serving personal plans, and Antigravity's terms forbid using it with products Google does not provide.
