What it is

You pay for Claude Code or Codex. Your apps cannot use that subscription — they need API credit you would buy separately. SheLLM runs the official CLI behind one endpoint that answers in both formats.

You already pay the subscription, so the marginal request costs nothing extra — and for Claude the CLI reports what it would have cost on the API, attributed to the key that made it. That is the figure above.

What you get

Get started

# Node.js 24 and a logged-in claude (or codex) on the same machine
$ git clone https://github.com/rodacato/SheLLM.git && cd SheLLM
$ npm install && npm link
$ shellm init
$ shellm start
$ curl http://127.0.0.1:6100/v1/chat/completions \
    -H "Authorization: Bearer $SHELLM_KEY" \
    -d '{"model":"claude-haiku","messages":[{"role":"user","content":"Hello"}]}'

When it does not work

A setting you changed did nothing.The config file is read once, when the service starts. Restart it: sudo systemctl restart shellm on a server, shellm restart on your machine.
A browser page is blocked by CORS.Calling /v1 from a page is off until SHELLM_CORS_ORIGINS names that exact origin — scheme, host and port, no trailing slash, and no wildcard.
curl works and your app gets 403.That key is scoped to browser origins, and yours is not on its list. A request with no Origin is accepted, which is why curl still works.
Anything else.shellm doctor checks the install and prints the fix beside whatever failed. shellm doctor --live spends one real request to prove the whole path.

What it is not

Not a way to share a subscription.One owner, their own apps.
Not a backend for coding agents.They drive their own CLI already.
Not an API-key gateway.LiteLLM does that better.
Not machine-scale.Quota is measured in human sessions.

Fair use and provider terms

SheLLM runs the official, unmodified CLI binaries. It never extracts OAuth tokens, never calls a provider's API with subscription credentials, and never pretends to be a different client. The remaining risk is yours.

ProviderStatus
Claude Supported. Anthropic forbids intermediating Claude.ai credentials; the official binary keeps its own login.
Codex Supported, at your own risk. codex exec is documented for scripts; anti-abuse classifiers are the real exposure, and a suspension takes the whole ChatGPT account.
Gemini Not supported. Gemini CLI stopped serving personal plans, and Antigravity's terms forbid it.
