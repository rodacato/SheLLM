What it is

A personal project: experiment with LLMs from your own software on the Claude Code or Codex subscription you already pay for, instead of buying API credit on top. SheLLM runs the official CLI behind one endpoint that answers in both the OpenAI and the Anthropic formats.

You already pay the subscription, so the marginal request costs nothing extra — and for Claude the CLI reports what it would have cost on the API, attributed to the key that made it. That is the figure above.

Every request starts the CLI and pays for it — about 0.9 s of a short call on the server, a cold start that is permanent. Streaming is what makes it usable: claude-sonnet starts writing at 1.7 s of a 5.5 s request (measured).

Get started

# Node.js 24 and a logged-in claude (or codex) on the same machine
$ git clone https://github.com/rodacato/SheLLM.git && cd SheLLM
$ npm install && npm link
$ shellm init
# prints the API key (shown once, store it now) — export it as SHELLM_KEY
$ shellm start
$ curl http://127.0.0.1:6100/v1/chat/completions \
    -H "Authorization: Bearer $SHELLM_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"claude-haiku","messages":[{"role":"user","content":"Hello"}]}'

import os
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:6100/v1", api_key=os.environ["SHELLM_KEY"])

stream = client.chat.completions.create(
    model="claude-sonnet",
    messages=[{"role": "user", "content": "Hello"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices:
        print(chunk.choices[0].delta.content or "", end="", flush=True)
import os
from anthropic import Anthropic

client = Anthropic(base_url="http://127.0.0.1:6100", api_key=os.environ["SHELLM_KEY"])

with client.messages.stream(
    model="claude-sonnet",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello"}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
import OpenAI from 'openai';

const client = new OpenAI({ baseURL: 'http://127.0.0.1:6100/v1', apiKey: process.env.SHELLM_KEY });

const stream = await client.chat.completions.create({
  model: 'claude-sonnet',
  messages: [{ role: 'user', content: 'Hello' }],
  stream: true,
});
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? '');
}
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic({ baseURL: 'http://127.0.0.1:6100', apiKey: process.env.SHELLM_KEY });

const stream = client.messages.stream({
  model: 'claude-sonnet',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'Hello' }],
});
stream.on('text', (text) => process.stdout.write(text));
await stream.finalMessage();

Every snippet streams, and runs as it is with SHELLM_KEY set. The SDKs also read the two export lines at the top, if you would rather not pass the URL.

Streaming, JSON Schema output and images behave the way the SDKs expect — what works today, each row a probe run against a live instance.

When it does not work

A setting you changed did nothing.The config file is read once, when the service starts. Restart it: sudo systemctl restart shellm on a server, shellm restart on your machine.
A browser page is blocked by CORS.Calling /v1 from a page is off until SHELLM_CORS_ORIGINS names that exact origin — scheme, host and port, no trailing slash, and no wildcard.
curl works and your app gets 403.That key is scoped to browser origins, and yours is not on its list. A request with no Origin is accepted, which is why curl still works.
Anything else.shellm doctor checks the install and prints the fix beside whatever failed. shellm doctor --live spends one real request to prove the whole path.

What it is not

Not a way to share a subscription.One owner, their own apps.
Not a backend for coding agents.They drive their own CLI already.
Not an API-key gateway.LiteLLM does that better.
Not machine-scale.Quota is measured in human sessions.

Fair use and provider terms

SheLLM runs the official, unmodified CLI binaries. It never extracts OAuth tokens, never calls a provider's API with subscription credentials, and never pretends to be a different client. The remaining risk is yours.

ProviderStatus
Claude Supported. Anthropic forbids intermediating Claude.ai credentials; the official binary keeps its own login.
Codex Supported, at your own risk. codex exec is documented for scripts; anti-abuse classifiers are the real exposure, and a suspension takes the whole ChatGPT account.
Gemini Not supported. Gemini CLI stopped serving personal plans, and Antigravity's terms forbid it.
